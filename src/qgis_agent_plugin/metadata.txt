description=Operation framework for QGIS Desktop: seventeen project, layer, style and processing operations with typed JSON contracts, progress, cancellation and execution ids, plus a dock window for running any of them by hand.
about=Adds an OperationRegistry and an OperationEngine to the QGIS Python Console (iface.agent_registry and iface.agent_engine), and an "QGIS Agent 操作" dock window that lists every registered operation, builds a form from its input schema and shows the execution record as JSON. Seventeen operations run there -- project.create/open/save/get_info; layer.add/list/get_info/set_visibility/sum_numeric_field/list_style_categories/get_qml/list_available_renderers/get_renderer/set_renderer; and processing.list_algorithms/get_algorithm_info/run_algorithm -- either on the main thread (engine.run_sync) or as a cancellable QgsTask (engine.submit, engine.get, engine.cancel). Every call answers with a JSON-serialisable record: status, progress, result, error code and execution id. Work is in-process; there is no network server, no socket and no remote caller. A path argument must be absolute; whether it can be read is QGIS's and the provider's answer.
