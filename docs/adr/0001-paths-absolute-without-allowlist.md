# 路径只要求绝对路径，不设根目录白名单

状态：已接受

所有路径参数走同一条判据：字形是绝对的、非空、无 NUL，三条都成立就放行；不判存在、不判是不是文件、不判在不在某个目录内。这些判断留给真正去读的一方，它的答案比预检新。

理由：调用方是 agent，不是终端用户。白名单要枚举出它未来会碰的所有数据位置，而这张表从写下的那天起就在过期——用户的数据散在多少个盘、多少个共享目录里，插件没有权威答案。相对的，进程能读写的范围本来就是 QGIS 自己的能力边界，收紧它属于新的设计，不属于一条配置。

被拒的选项：

- **根目录白名单**：早期配置里有过 `allowed_data_roots`，现在已移除，旧配置里残留的键被当作"不认识的键"忽略。
- **相对路径按工作目录解析**：同一个调用在不同启动目录下指向不同文件，调用方无法预知结果。

后果：一次成功调用可以读到这台机器上进程可读的任何位置。这是能力决定，不是遗漏；要在某个部署里收紧，应写成新的边界，而不是在判据里加分支。
